## 2. 저장소는 세 번 바꿀 수 있게

처음부터 데이터를 어디에 둘지 바꿀 수 있게 만들었다. 코드 한 줄로 모드를 고른다.

| 모드 | 저장 위치 | 영구 저장 | 공유 |
|---|---|---|---|
| `local` | 브라우저 localStorage | ❌ | ❌ |
| `json` | 정적 JSON 파일 | ❌ | ✅ |
| `api` | **Neon PostgreSQL** | ✅ | ✅ |

첫날 Vercel KV로 시작했다가 바로 **Neon PostgreSQL**로 갈아탔다. Vercel 마켓플레이스에서 Neon을 연결하면 환경 변수가 자동으로 들어와서 설정이 거의 없었고, 무료 티어로 충분했다.

---

## 3. 한글 입력의 함정: Enter 두 번

세부 항목을 입력하고 Enter를 누르면 **항목이 두 번 추가되는** 버그가 있었다. 한글은 글자를 조합하는 중(IME composition)에도 Enter 이벤트가 한 번 더 들어오기 때문이다.

```ts
if (e.nativeEvent.isComposing) return; // 한글 조합 중 Enter는 무시
```

이 한 줄로 해결했다. 한국어 서비스라면 **입력창마다 한 번씩 꼭 만나는 문제**라, 이제는 처음부터 넣어 두는 편이다.

## 4. 작은 정리들

- 세부 항목을 **여러 개 한 번에** 입력할 수 있게

## 💡 배운 것

1. **저장 방식은 갈아끼울 수 있게.** 로컬로 빠르게 시작하고 나중에 DB로 옮기기 쉬웠다.

3. **나를 위한 도구는 이틀이면 충분하다.** 완벽하게 만들기보다 바로 쓰기 시작하는 게 중요했다.
