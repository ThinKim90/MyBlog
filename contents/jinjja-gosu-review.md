# 진짜 고수 제작기
**트렌드로 역발상 종목을 추천하는 패러디 앱**

어떤 키워드가 뜨면 사람들은 바로 관련주를 떠올린다. **진짜 고수**는 거기서 한 번 더 비튼다.
"다들 이 종목을 살 때, 진짜 고수는 이걸 산다." 오늘의 트렌드를 가져와서 *사람들이 예상하는 종목*과 *AI가 찾아낸 엉뚱한 역발상 종목*을 나란히 보여 주는 패러디 웹앱이다.

> ⚠️ 엔터테인먼트용 서비스이고 실제 투자 조언이 아니다. 지금은 서비스를 닫았다.

## 1. 어떻게 동작하나

1. **오늘의 트렌드 가져오기** — 한국 실시간 트렌드 키워드
2. **정배 종목 찾기** — 그 키워드를 보면 누구나 떠올릴 종목
3. **역발상 종목 찾기** — Gemini가 2~3단계 건너뛴 연결고리로 엉뚱한 종목을 고르고, 그럴듯한 이유를 유머러스하게 붙인다
4. **실시간 주가 붙이기** — 한국투자증권(KIS) API
5. **캐싱** — 한 번 만든 추천은 Vercel KV(Redis)에 저장해 두고 2시간마다 새로 만든다

화면에서는 정배 종목과 역발상 종목 사이에 **VS**를 두고, 역발상 쪽을 노란색으로 강조했다.

---

## 2. 발음 유사도 매칭을 버린 이유

처음엔 매칭 전략이 두 가지였다.

- **발음/초성 유사도**: 트렌드 키워드와 이름이 비슷하게 들리는 종목
- **의미적 연관성**: AI가 찾아내는 창의적인 연결고리

둘째 날, 발음 유사도 매칭을 **완전히 걷어냈다.** 이름만 비슷한 종목은 억지스럽기만 하고 웃기지 않았다. 의미로 연결한 추천만 남기고, 실패하면 최대 3번 다시 시도하게 바꿨다. 그 덕분에 VS 화면도 늘 같은 모양으로 보여 줄 수 있게 됐다.

> ✍️ 기억에 남는 추천 결과 (웃겼던 것, 너무 억지였던 것)

---

## 3. 데이터 소스 바꾸기의 연속

외부 API에 기대는 서비스라 데이터 소스를 여러 번 갈아탔다.

- **주가**: Yahoo Finance로 시작 → 버전이 바뀌면서 깨짐 → **한국투자증권 API**로 교체
- **트렌드**: Google Trends(비공식)를 기본으로 두고 여러 소스를 순서대로 시도하다가, 결국 **Gemini에 웹 검색을 붙여 직접 찾게** 하는 쪽을 1순위로
- **AI 모델**: Gemini 1.5 Flash → 2.0 실험판 → **2.5 Flash 안정판**, 마지막엔 SDK 자체를 새 라이브러리로 교체

비공식 API와 실험판 모델은 빨리 시작하기엔 좋지만 **언제든 깨질 수 있다.** 운영할 서비스라면 처음부터 안정판을 고르는 게 낫다.

---

## 4. 크론과의 싸움: Hobby 플랜의 벽

"매일 아침 7시 자동 갱신"이 컨셉이었는데, 이게 생각보다 어려웠다.

- Vercel Cron을 설정했지만 대시보드에서 따로 켜야 했다
- **Hobby(무료) 플랜은 크론을 하루 1번만** 돌릴 수 있었다
- 2시간마다 갱신하고 싶어서 결국 **GitHub Actions가 2시간마다 API를 호출**하는 구조로 바꿨다
- 그 과정에서 크론 인증, 빌드 설정 충돌, 캐시 문제로 강제 재배포 커밋이 여러 번 쌓였다

> ✍️ 배포 문제로 가장 답답했던 순간

## 💡 배운 것

1. **재미는 억지가 아니라 그럴듯함에서 나온다.** 발음 말장난보다 의미 연결이 훨씬 웃겼다.
2. **외부 API에 기대는 서비스는 갈아탈 각오를 한다.** 비공식 API, 실험판 모델은 특히.
3. **무료 플랜의 제약은 시작 전에 확인한다.** 크론 하나 때문에 구조를 바꿨다.

> ✍️ 서비스를 닫은 이유 / 다시 연다면 바꾸고 싶은 것
